# 03: 字幕條長度與顯示規則

**What to build:** 產出的字幕條不再過長或一閃即逝：超過 1.2 秒靜音、超過 28 字數單位、超過 6 秒都會切開；中英混排的併字空白正確；超過 14 字數單位的字幕條在畫面上以兩行均衡呈現；每條至少顯示 0.8 秒。

**Blocked by:** 02

**Status:** done

**參考：** spec `docs/specs/2026-10-19-mlx-pyannote-meeting-pipeline-design.md`；用語依 `GLOSSARY.md`；已驗證的測試與實作在實作計畫 Task 2（字數單位、併字、兩行換行）、5（切分條件、最短顯示）、7（SRT 兩行輸出）。

- [ ] 字數單位：中文字 1、英文單字 1.5、標點與空白 0
- [ ] 併字：中中、中與標點不加空白；英英、中英保留一個空白
- [ ] 四個切分條件（換人、靜音 > 1.2 秒、> 28 單位、> 6 秒）皆生效；字幕條可剛好 28 單位
- [ ] 超過 14 單位時在最均衡處換行，最多兩行，第二行不以標點開頭
- [ ] 短於 0.8 秒的字幕條延長結束時間但不超過下一條開始，不與其他字幕條合併
