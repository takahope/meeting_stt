# 會議影音零提示詞互動處理 Skill 使用指南

本技能讓您或您的同事在**完全不需自備提示詞（Prompt）**的情況下，只需將會議**音訊**或**影片**檔傳給 Antigravity Agent，系統便會**主動彈出勾選清單**供您挑選所需的文件，並精準生成最高 9 份標準化中英雙語會議文件。

---

## 核心特色與運作方式

1. **零提示詞觸發（Zero-Prompt Trigger）**：
   - 同事只要發送錄音檔或影片路徑，無需輸入任何提示詞指令，系統自動啟動。
2. **強制互動勾選閘門（Interactive Selection Gate）**：
   - AI 在開始生成前，**必定會主動彈出互動視窗**（Checkbox Modal），讓您勾選本次想輸出的文件種類（可一鍵全選 9 份，或自由勾選特定幾份）。
   - **AI 僅針對已勾選的項目進行轉錄、翻譯與報告輸出**，不浪費時間生成不需要的檔案。
3. **影片自動轉音訊前置處理**：
   - 若提供影片（如 Zoom / Teams / Meet 錄影 `.mp4`, `.mov` 等），背景自動在 1~3 秒內利用 `ffmpeg` 剝離影像軌，抽取為輕量高品質的 `.m4a`（體積縮小 90% 以上，確保低於 100 MB 上限）。
4. **零外部模型依賴**：完全不依賴本地 Whisper、pyannote、PyTorch 等繁重模型，直接運用原生多模態音訊理解。
5. **完整 9 份標準化文件支援**：包含 4 份原文核心文件 + 4 份雙向翻譯文件 + 1 份時間線中英雙語對照逐字稿。

---

## 快速開始

### 方式一：在當前專案直接使用（推薦）
本技能已內建於此專案的 `.agents/skills/meeting-audio-processor/`。
同事只要開啟本專案，並在對話視窗中輸入：
```text
team_meeting.mp4
```
或直接將音訊/影片檔拖曳至對話框，**不需要任何其他說明提示詞**，AI 就會自動彈出勾選清單供您選擇，確認後產出所選文件！

---

### 方式二：安裝至同事個人電腦的全域環境 (Global Skill)
若同事希望在自己的任何資料夾或專案中都能使用，只需在終端機執行此行指令：

```bash
mkdir -p ~/.gemini/config/skills && cp -r .agents/skills/meeting-audio-processor ~/.gemini/config/skills/
```

安裝後，在任何目錄下啟動 Antigravity，只要丟音訊或影片檔就會自動觸發！

---

## 支援格式與依賴
- **純音訊格式**：`.m4a`, `.mp3`, `.wav`, `.aac`, `.flac`, `.ogg`
- **影片格式（自動萃取）**：`.mp4`, `.mov`, `.webm`, `.mkv`, `.avi`, `.m4v`
- **影片轉檔依賴**：系統需具備 `ffmpeg`（Mac 上可透過 `brew install ffmpeg` 安裝）。

## 可供勾選之 9 份文件清單

產出檔案將集中收納於 `./minutes_<主檔名>/` 目錄：

| 編號 | 檔案名稱 | 說明 |
|:---:|---|---|
| **01** | `01_transcript_[orig].md` | **原文逐字稿**（說話者分離、去除無效口頭贅字） |
| **02** | `02_decisions_[orig].md` | **原文決策摘要**（定案決策、被否決/保留方案） |
| **03** | `03_action_items_[orig].md` | **原文待辦事項**（表格：任務、負責人、截止日、優先級、驗收條件） |
| **04** | `04_meeting_minutes_[orig].md` | **原文專業會議報告**（Executive Summary、議題深入討論、風險與里程碑） |
| **05** | `01_transcript_[trans].md` | **翻譯逐字稿**（英文 ➔ 繁體中文，或中文 ➔ 專業英文） |
| **06** | `02_decisions_[trans].md` | **翻譯決策摘要**（專有名詞高度對齊） |
| **07** | `03_action_items_[trans].md` | **翻譯待辦事項**（跨語言任務與負責人對照表） |
| **08** | `04_meeting_minutes_[trans].md` | **翻譯專業會議報告**（高階主管報告格式） |
| **09** | **`05_bilingual_timeline_transcript.md`** | **時間線中英雙語對照逐字稿**（`[MM:SS]` 時間區間 + 說話者 + 原文/譯文並排） |
